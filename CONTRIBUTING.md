## Contributing

Thanks for helping improve the Unified Node Protocol.

Guidelines
- Discuss significant changes in an issue first.
- Keep changes focused. One topic per PR.
- Run `buf lint` locally before pushing.

Dev Quickstart
1) Install buf: https://buf.build
2) Lint: `buf lint proto`
3) Generate (Go example): `buf generate proto`
